微反馈动效 · 设计规格

在现有基础上注入有意义的触感反馈，让浏览体验更「活」

1. 光标状态分层 (CustomCursor 升级)

现有光标只有两种状态：默认 (dot+corner旋转) 和锁定 (corner贴附到.cursor-target)。升级为 4 种状态：
默认 · 漫游
dot (5px 实心) + 4 corner brackets 缓慢旋转 (8s/圈)
dot opacity: 1.0, corners opacity: 0.7
链接悬停 · 聚焦
dot 放大至 8px + 辉光增强
corners 停止旋转并收拢到元素边缘
dot opacity: 0, corners→snap to target rect
按钮悬停 · 磁吸
corners 贴附按钮圆角边缘 (border-radius follow)
dot 消失，corners 描边色跟随按钮的 hover color
过渡 150ms ease-out
文字选择 · 隐退
当检测到用户正在拖拽选文时
光标整体 opacity→0 (200ms)，避免干扰阅读
选文结束恢复

2. 方向感知按钮悬停

按钮 hover 时，辉光/颜色填充从光标进入的方向开始扩散，而不是全局均匀过渡。
← 从左进入
↑ 从下进入
→ 从右进入
实现: onMouseEnter 计算 cursor 相对于 button center 的角度
→ 设置 CSS gradient 的 direction angle
→ 配合 transition 产生方向性扩散效果
约 15 行 Motion + CSS 代码

3. 粒子近场响应 (Particles 升级)

现有的 Particles Canvas 是纯被动的背景装饰。升级为 对光标位置有微弱响应：
• 光标 150px 范围内的粒子轻微远离光标 (排斥力，最大偏移 ~8px)
• 光标离开后粒子 spring 回原位 (回弹持续时间 ~600ms)
• 响应力随距离衰减 (inverse-square falloff)
• 用 requestAnimationFrame 直接在 Canvas 上计算，不触发 React 重渲染
效果极微弱但显著提升「空间纵深感」—— 用户感觉页面在回应他的存在

4. 滚动显影差异化 (ScrollReveal 升级)

当前 ScrollReveal 所有元素使用相同的 blur+y 入场。升级为按元素类型自适应：
标题
y: 36, blur: 16px
duration: 1.1s
ease: power4.out
正文
y: 18, blur: 6px
duration: 0.7s
ease: [0.16, 1, 0.3, 1]
卡片
y: 32, blur: 10px
duration: 0.9s
ease: [0.16, 1, 0.3, 1]
CTA按钮
y: 24, blur: 0
duration: 0.6s
ease: [0.34, 1.56, 0.64, 1]
ScrollReveal 新增 variant prop:
variant: "heading" | "body" | "card" | "cta" | "image"
每个 variant 预设不同的 animation params
向后兼容，不传 variant 使用默认值

5. 按钮按压触感

现有 Hero 的 CTA 按钮已有 whileTap: scale(0.97)，但其他按钮（Navbar、Contact 等）缺少统一处理。
:active 状态
→
hover 状态
统一动作: scale(0.97) + translateY(1px) on :active / whileTap
时长: 100ms, ease: [0.34, 1.56, 0.64, 1] (轻微 overshoot 回弹)
适用: 所有可点击按钮 (CTA / Nav 链接 / Form submit)

6. Navbar 滚动响应

Navbar 在页面滚动时添加微妙的状态变化，让用户感知到页面深度：
• scrollY = 0: Navbar 背景完全透明，融入 Hero 视频
• scrollY > 100: bg-bg-deep/0.6 + backdrop-blur 逐渐显现 (200ms过渡)
• scrollY > 200: 完全 opaque，底部出现 1px 分割线 (border-white/0.06)
• 使用 Motion useScroll + useTransform，不触发 React 重渲染
const { scrollY } = useScroll()
const navBg = useTransform(scrollY, [0, 200], ["transparent", "rgba(5,5,9,0.85)"])
const navBorder = useTransform(scrollY, [0, 200], [0, 1])
